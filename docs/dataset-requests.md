# Dataset access request drafts

Ready-to-send email drafts for the two request-only corpora. Fill in the
bracketed fields before sending. (How We Type needed no request — its

## (a) Clarkson II — via CITeR

- Dataset page: https://citer.clarkson.edu/clarkson-university-keystroke-dataset-ii/
- No public download or request form; the page points to the CITeR contacts
  page (https://citer.clarkson.edu/contacts/). The dataset is credited to
  Christopher Murphy, Jiaju Huang, Daqing Hou and Stephanie Schuckers
  (IJCB 2017: *Shared dataset on natural human-computer interaction to
  support continuous authentication research*).
- Suggested recipients: Prof. Daqing Hou and Prof. Stephanie Schuckers
  (Clarkson University), or the general CITeR contact from the contacts page.

**Subject:** Request for Clarkson II keystroke dataset — non-commercial research use

Dear Professors Hou and Schuckers,

I am writing to request access to the Clarkson University Keystroke Dataset
II (the uninstructed longitudinal collection of 103 users / 12.9 million
keystrokes, described in Murphy et al., IJCB 2017).

I work on [project name], a non-commercial research project building
generative models of human typing: models that reproduce realistic keystroke
timing, error and correction behavior, rather than authenticate users. The
Clarkson II corpus is uniquely valuable to us because it is uninstructed and
longitudinal — it shows how real typing behavior varies across sessions,
applications and months, which no transcription-task corpus captures.

Intended use: research only. We would use the data to fit and evaluate
statistical/ML models of typing dynamics. No commercial use, no
redistribution, and no attempt to re-identify participants.

Data handling: the dataset would be stored on access-controlled machines
available only to project members, used solely for the purpose above,
deleted on request or at project end, and any publications would cite the
IJCB 2017 paper and acknowledge CITeR. We are happy to sign a data use
agreement in whatever form you require.

Could you let me know the procedure for obtaining the dataset (and any
agreement you need from us)?

Thank you for making this resource available.

Best regards,
[Name]
[Affiliation / project page]
[Email]

## (b) Buffalo CUBS — cubsinfo@buffalo.edu

- Dataset: the UB CUBS keystroke dataset (Sun, Ceker & Upadhyaya, WIFS 2016:
  *Shared keystroke dataset for continuous authentication*) — 148 subjects
  over three sessions, 73 of whom typed on different keyboards per session.

**To:** cubsinfo@buffalo.edu
**Subject:** Request for CUBS keystroke dataset (WIFS 2016) — non-commercial research use

Dear CUBS team,

I would like to request access to the shared keystroke dataset described in
Sun, Ceker and Upadhyaya, "Shared keystroke dataset for continuous
authentication" (WIFS 2016) — the 148-subject collection with both fixed-text
and free-text sessions.

I work on [project name], a non-commercial research project building
generative models of human typing (keystroke timing, errors and corrections),
not an authentication product. Your dataset is particularly relevant because
73 of the subjects typed on a different keyboard in each session: that
within-person, across-keyboard variation is exactly what we need to separate
typist behavior from hardware effects in our models.

Intended use: research only — model fitting and evaluation. No commercial
use, no redistribution, and no attempt to re-identify participants.

Data handling: the data would live on access-controlled machines restricted
to project members, be used only for the purpose above, and be deleted on
request or at project end. Publications would cite the WIFS 2016 paper. We
will gladly sign your release or data use agreement.

Could you tell me the steps to obtain the dataset?

Thank you,
[Name]
[Affiliation / project page]
[Email]
